# AICosplayForGamePlayer - 游戏玩家AI角色扮演系统

## 项目概述
AICosplayForGamePlayer是一个为游戏玩家提供AI角色扮演服务的Web应用，让玩家能够与AI扮演的游戏角色进行对话互动。

## 技术栈选择

### 后端技术栈
- **Spring Boot 3.2.2**: 选择最新的Spring Boot版本，享受更好的性能和新特性。
- **Spring AI**: 用于集成大模型功能（相比LangChain的选择理由详见下文）。
- **Spring Security**: 提供安全的用户认证和授权机制。
- **Spring Data JPA**: 简化数据库操作。
- **MySQL**: 关系型数据库，存储用户、对话和消息数据。

### 前端技术栈
- **Vue.js 3**: 轻量级、高性能的前端框架。
- **Vue Router**: 实现前端路由管理。
- **Axios**: 处理HTTP请求。
- **Bootstrap**: 提供响应式UI组件。

## 系统架构

1. **前端层**：
   - 用户界面组件（登录、注册、聊天界面）
   - 路由管理
   - API请求处理

2. **后端层**：
   - 控制器层：处理HTTP请求，提供RESTful API
   - 服务层：实现业务逻辑，包括大模型集成
   - 数据访问层：与数据库交互
   - 安全层：处理认证和授权

3. **外部服务**：
   - OpenAI API

## 交互流程

1. **用户输入处理**：
   - 用户通过前端界面输入对话内容
   - 前端将输入内容发送至后端API

2. **后端处理**：
   - 验证用户身份和权限
   - 保存用户消息到数据库
   - 构建对话上下文
   - 调用AIService与大模型交互
   - 接收大模型生成的回复
   - 保存AI回复到数据库

3. **响应返回**：
   - 后端以阻塞式方式返回处理结果
   - 前端更新UI，显示对话内容

## 环境要求

### 后端
- JDK 17或更高版本
- Maven 3.6+ 或 Gradle 7.0+
- MySQL 8.0+
- OpenAI API密钥（或其他兼容的大模型API密钥）

### 前端
- Node.js 14+ 
- npm 6+ 或 yarn 1.22+
