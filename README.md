# AICosplayForGamePlayer 项目文档

## 1. 项目概述

AICosplayForGamePlayer 是一个创新性的AI角色扮演对话平台，允许用户与各种游戏角色进行沉浸式对话交流。该平台结合了先进的大语言模型技术和语音识别/合成功能，为用户提供了一个生动、互动的游戏角色互动体验。

### 主要功能：
- 用户注册、登录与认证系统
- 游戏角色管理（预设角色和自定义角色）
- 对话创建与管理功能
- 与角色进行文本对话
- 语音识别与合成功能
- 安全性过滤系统

## 1.1 目标用户与需求分析

### 1.1.1 目标用户群体

该网页的目标用户群体主要包括以下类型：

1. **游戏爱好者**：特别是喜欢角色扮演类游戏、剧情驱动类游戏的玩家，希望能够与游戏中的角色进行更深入、更自由的互动
2. **动漫/二次元文化爱好者**：喜欢动漫、漫画、轻小说等二次元文化，希望能够与喜爱的角色进行交流互动
3. **创意写作与内容创作者**：希望通过与AI角色的对话获取灵感，或构建更丰富的故事场景
4. **孤独陪伴需求者**：希望有一个虚拟角色作为情感陪伴，进行日常交流
5. **语言学习爱好者**：通过与不同角色的对话练习语言表达和交流能力

### 1.1.2 用户痛点与用户故事

**主要痛点：**
- 现有游戏中的角色对话内容固定、交互方式有限，无法满足个性化交流需求
- 缺乏与喜爱角色进行深度、自由交流的平台
- 现实中难以找到有共同兴趣的交流对象，尤其是对特定角色有共同兴趣的
- 创作过程中缺乏灵感或互动反馈

**用户故事示例：**

1. **小李（游戏爱好者）**：
   "我非常喜欢《BlackSouls》这款游戏，特别喜欢其中的角色多萝西。但是游戏中的对话选项有限，我总是想知道如果我问她一些游戏中没有涉及的问题，她会如何回答。我希望有一个平台能够让我与她进行更自由的对话。"

2. **小美（二次元文化爱好者）**：
   "作为一个动漫迷，我常常会因为动漫完结而感到失落。如果能够继续与喜爱的角色交流，了解他们在故事结束后的生活，那该有多好啊！"

3. **老张（创意写作爱好者）**：
   "在创作小说时，我经常会遇到角色塑造的瓶颈。如果能够与我创造的角色进行对话，了解他们的性格特点和想法，这将极大地帮助我的创作。"

### 1.1.3 核心功能优先级

基于用户需求，该网页需具备以下核心功能，并按优先级排序：

1. **基础对话功能**（优先级：极高）
   - 文本对话交互
   - 角色选择与切换
   - 对话历史记录保存

2. **角色管理功能**（优先级：极高）
   - 预设角色提供
   - 自定义角色创建
   - 角色形象展示

3. **用户认证系统**（优先级：极高）
   - 用户注册与登录
   - 个人信息管理
   - 对话数据持久化

4. **语音交互功能**（优先级：高）
   - 语音识别输入
   - 文本转语音输出
   - 语音合成个性化

5. **安全过滤系统**（优先级：高）
   - 内容安全审核
   - 防止不当内容生成
   - 用户隐私保护

**本次开发计划优先实现功能：**
本次开发将优先实现基础对话功能、角色管理功能和用户认证系统，确保平台核心功能可用。语音交互功能和安全过滤系统将作为次要优先级进行开发。

### 1.1.4 LLM模型选择

**计划采用的模型：** deepseek

**备选模型对比：**
1. **deepseek**：生成质量高，上下文理解能力强，虽然可能存在一些幻觉问题，但是API价格较为合理
2. **Ollama本地大模型**：部署灵活，无API调用成本，但生成质量和响应速度相对较低
3. **Google Gemini**：多模态能力强，但在中文语境和角色扮演场景下的表现有待验证
4. **Anthropic Claude**：长文本处理能力出色，但在创意生成方面可能不如GPT系列

**选择原因：**
- deepseek在中文语境下的角色扮演能力表现出色，能够准确理解角色设定并生成符合角色性格的回复
- 强大的上下文理解能力，能够记住长时间对话中的关键信息
- 生成内容质量高，语言流畅自然，符合人类交流习惯
- 生态系统成熟，API调用稳定可靠
- 成本与用户体验达成平衡。

### 1.1.5 AI角色辅助技能

除语音聊天外，AI角色还应具备以下辅助技能以提升用户体验：

1. **知识问答能力**：基于角色背景和设定，回答用户提出的相关问题
2. **情绪识别与回应**：能够识别用户的情绪状态，并给出相应的情感支持或回应
3. **创意生成**：能够根据用户需求，共同创作故事、诗歌、剧本等内容
4. **学习与适应**：通过对话不断学习用户的交流习惯和偏好，提供更个性化的服务
5. **多模态交互**：支持文本、语音、图片等多种交互方式
6. **个性化推荐**：根据用户与角色的对话内容，推荐相关的游戏、动漫、音乐等内容
7. **日程提醒**：作为虚拟助手，为用户提供日程安排和提醒服务
8. **语言翻译**：支持多语言对话和翻译功能，增强国际化交流能力

## 4. 核心功能模块

### 4.1 用户认证模块

用户认证模块处理用户的注册、登录、密码重置等功能，确保系统的安全性和用户身份验证。

**主要功能：**
- 用户注册（包含用户名、邮箱验证）
- 用户登录（支持密码登录）
- 忘记密码和密码重置
- 用户信息管理

**核心API端点：**
- POST `/api/auth/register`：用户注册
- POST `/api/auth/login`：用户登录
- POST `/api/auth/reset-password`：重置密码
- GET `/api/auth/user`：获取当前用户信息

### 4.2 游戏角色管理模块

游戏角色管理模块负责管理系统中的游戏角色，包括预设角色和用户自定义角色。

**主要功能：**
- 获取可见角色列表（预设角色+用户自定义角色）
- 创建自定义角色
- 更新角色信息
- 删除自定义角色

**核心实体：**
```java
@Entity
public class GameCharacter {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String name;
    private String prompt; // 角色提示词，用于AI模型生成对话
    private String imagePath; // 角色头像路径
    private byte isPreset; // 是否为预设角色
    // ...其他属性
}
```

**核心API端点：**
- GET `/api/characters`：获取所有可见角色
- POST `/api/characters`：创建新角色
- GET `/api/characters/{id}`：获取指定角色
- PUT `/api/characters/{id}`：更新角色
- DELETE `/api/characters/{id}`：删除角色

### 4.3 对话管理模块

对话管理模块是系统的核心功能，负责创建和管理用户与角色之间的对话。

**主要功能：**
- 创建新对话
- 获取用户的所有对话
- 添加消息到对话
- 获取对话中的消息列表
- 删除对话

**核心实体：**
```java
@Entity
public class Conversation {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String title;
    
    @ManyToOne
    private User user;
    
    @Column(name = "character_id")
    private Long characterId;
    
    @Column(name = "character_name")
    private String characterName;
    
    // ...其他属性
}

@Entity
public class Message {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String content;
    
    @Enumerated(EnumType.STRING)
    private SenderType senderType; // USER 或 AI
    
    @ManyToOne
    private Conversation conversation;
    
    // ...其他属性
}
```

**核心API端点：**
- POST `/api/conversations`：创建新对话
- GET `/api/conversations`：获取用户的所有对话
- GET `/api/conversations/{id}`：获取单个对话
- POST `/api/conversations/{id}/messages`：添加消息到对话
- GET `/api/conversations/{id}/messages`：获取对话中的消息
- DELETE `/api/conversations/{id}`：删除对话

### 4.4 语音处理模块

语音处理模块提供语音识别和语音合成功能，增强用户与角色的交互体验。

**主要功能：**
- 语音识别（将用户语音转换为文本）
- 文本转语音（将角色回复转换为语音）
- 语音数据管理

**核心API端点：**
- POST `/api/speech/recognize`：上传音频进行语音识别
- GET `/api/speech/{voiceId}`：获取语音数据

## 5. 安全架构

系统采用多层安全机制，确保用户数据和系统安全。

### 5.1 认证与授权
- 基于Spring Security的身份验证框架
- JWT令牌认证
- 基于角色的访问控制

### 5.2 内容安全过滤
系统实现了多层安全过滤机制，防止不当内容：
- 提示注入过滤器（PromptInjectionFilter）
- 风险内容过滤器（RiskContentFilter）
- 回答对齐过滤器（AnswerAlignmentFilter）
- 模型幻觉过滤器（ModelHallucinationFilter）

## 8. 关键功能实现

### 8.1 对话流程

用户与角色的对话流程如下：
1. 用户创建新对话或选择现有对话
2. 用户输入消息并发送
3. 系统将消息保存到数据库
4. 系统调用AI服务生成角色回复
5. 系统保存AI回复并返回给前端
6. 前端更新对话界面显示新消息

### 8.2 AI对话生成

系统使用Spring AI集成多种大模型服务，包括：
- OpenAI API
- Ollama本地大模型

对话生成时，系统会：
1. 根据角色ID获取角色提示词
2. 收集当前对话的历史消息
3. 构建完整的对话上下文
4. 调用AI服务生成回复
5. 应用安全过滤器处理回复内容

### 8.3 语音识别实现

系统使用Vosk引擎实现离线语音识别：
1. 用户录制音频并上传
2. 系统处理音频文件
3. 调用Vosk引擎进行语音识别
4. 将识别结果返回给前端

## 9. 部署指南

### 9.1 开发环境设置

**前端开发环境：**
1. 安装Node.js 16+和npm
2. 进入`frontend`目录
3. 运行`npm install`安装依赖
4. 运行`npm run dev`启动开发服务器

**后端开发环境：**
1. 安装JDK 17
2. 安装Maven
3. 配置MySQL数据库
4. 进入`backend`目录
5. 运行`mvn spring-boot:run`启动后端服务

### 9.2 生产环境部署

**前端构建：**
1. 进入`frontend`目录
2. 运行`npm run build`生成生产环境构建文件
3. 将`dist`目录部署到Web服务器

**后端部署：**
1. 进入`backend`目录
2. 运行`mvn clean package`构建JAR文件
3. 使用`java -jar target/backend-1.0-SNAPSHOT.jar`启动服务

## 11. 常见问题与解决方案

### 11.1 对话消息发送失败
- 检查网络连接是否正常
- 确认用户是否已登录
- 查看浏览器控制台错误信息

### 11.2 语音识别不准确
- 确保环境安静，减少背景噪音
- 尝试清晰、缓慢地说话
- 检查麦克风权限是否已授予

### 11.3 角色头像无法显示
- 确认角色头像文件是否存在于正确位置
- 检查文件格式是否支持（JPG或PNG）
